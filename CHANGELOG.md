# Changelog

## 1.2.0

- Add Chinese and English interface selection, applied immediately and saved between launches.
- Translate sound descriptions, menu bar actions, status messages and diagnostics.

## 1.1.1

- Use a persistent local signing identity to preserve permission identity across builds.
- Add sound and Input Monitoring diagnostics.

## 1.1.0

- Include ten sets of individual key recordings and separate sounds for larger keys.
- Use a 64-frame audio buffer where supported, with preloaded samples and concurrent mixing.
- Preserve sound selection by profile ID.

The public repository starts with the 1.2.0 source snapshot. Earlier development history and retired recordings are not included.
